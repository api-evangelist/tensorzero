# TensorZero

> TensorZero is an open-source, self-hosted LLMOps platform that unifies an LLM Gateway (access every major model provider through one unified, OpenAI-compatible API with <1ms p99 overhead), Observability (store inferences and feedback in your own database), Evaluation (heuristics and LLM judges), Optimization (improve prompts, models, and inference strategies from metrics and human feedback), and Experimentation (A/B testing, routing, fallbacks, retries). NOTE: as of 2026 the project is no longer maintained — the source remains available on GitHub and the last Python client (2026.6.0) is on PyPI, but the hosted product has wound down and all org repositories are archived.
